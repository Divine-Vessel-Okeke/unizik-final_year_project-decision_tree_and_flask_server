# Design and Implementation of a Predictive Fraud Detection System for University E-payment Portals using Decision Tree Classification (Final Year Project) - DECISION TREE + FLASK SERVER

## Setup Instructions

1. **Create your virtual environment:**

   ```
   python -m venv .venv
   ```

2. **Activate your virtual environment:**

   ```
   source .venv/bin/activate  # Linux/Mac
   .venv\Scripts\activate  # Windows
   ```

3. **Install dependencies:**

   ```
   pip install -r requirements.txt
   ```

## Execution

1. **Start the API Server:**

   ```
   python app/main.py
   ```
